В чём проблема

Шторм на Каспии качает судно — груз бьётся, смещается и ломается

В акваторию постоянно везут дорогое оборудование: хрупкую электронику, чувствительные датчики, измерительные приборы. Промышленные стабилизаторы решают задачу, но они громоздкие и дорогие.

Активный подвес

Платформа компенсирует наклон корпуса

  • → Датчик измеряет наклон корпуса
  • → Мотор поворачивает платформу в обратную сторону
  • → Центр тяжести ниже оси — гравитация помогает
Как работает управление

Обратная связь: гироскоп → мотор

stabilizer.py 
from pybricks.ev3devices import Motor, GyroSensor from pybricks.parameters import Port from pybricks.tools import wait gyro = GyroSensor(Port.S1) # датчик на корпусе motor = Motor(Port.A) # мотор оси платформы KP = 1.0 # усиление: подбирается опытом GEAR = 3 # градусов мотора на 1° платформы gyro.reset_angle(0) while True: roll = gyro.angle() # наклон корпуса motor.track_target(-roll * KP * GEAR) wait(10)
Вывод

Активный карданный подвес держит платформу горизонтально при качке корпуса

Для хрупких грузов такое решение легче и дешевле громоздких стабилизаторов, а модель на LEGO EV3 позволяет проверить принцип на опыте.
